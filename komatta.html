1はじめる前に揃えるもの

  • Claude の有料プラン（月 20〜200 ドル）。無料プランでは作る係（Claude Code）が使えません
  • パソコン：Mac か Windows。ここ数年のものなら足ります
  • スマホ：iPhone か Android。どちらでも同じアプリになります
  • クレジットカード 1 枚：会話の AI（OpenAI）の前払いと、発音評価（Azure）の登録に使います。どちらも使った分だけで、月数百円が目安
  • メールアドレス：登録が 5 つほどあります（GitHub・Vercel・Supabase・OpenAI・Azure）。全部同じアドレスで構いません
  • 紙とペン：途中で「自分で決めるパスワード」が 1 つ出ます（データベース用）。紙に書いて、無くさない所へ

2Claude Code の入れ方（黒い画面は使いません）

  1. Claude のデスクトップアプリを入れて、いつものアカウントでサインインする
  2. 左の列にある 「Code」 のタブを開く。これが「作る係」です
  3. 「フォルダを選ぶ」と聞かれたら、自分の名前のフォルダの直下に「EnglishLab」という新しいフォルダを作って選ぶ。デスクトップや「書類」の中は避けてください（iCloud や OneDrive が同期して、動きが重くなります）
  4. 「このフォルダを信頼しますか」と出たら 「はい」
  5. 入力欄の近くにある モードの表示を「Accept edits（編集を許可）」にする。これで、ファイルを作るたびに聞かれなくなります。消す・送る・お金がかかる操作は、この設定でも必ず聞いてきます
  6. 案内ページの「指示文」をコピーして、入力欄に貼る。〔　〕を自分のことに書き換えて送る

3これは壊れていない（よく出る 7 つ）

許可を求める画面が出る
AI がファイルを作る・コマンドを動かす前の確認です。読んで「Yes（はい）」。危ないものは AI が先に止める約束になっています
ブラウザが勝手に開いて、ログインを求める
GitHub・Vercel・Supabase などへのログインです。ここだけは人の手が要ります。ログインして、画面に「You can close this window」や「Authorize」が出たら押し、Claude Code に戻って「できました」と書く
黒い画面で「Password:」と出て、打っても何も表示されない
Mac のログインパスワードを求めています。打っても文字は出ません。そのまま打って return
「上限に達しました。○時に再開できます」
Claude の有料プランの時間あたりの枠です。待てば戻ります。その間に別のことをしてください
Mac で「コマンドラインツールをインストールしますか」
「インストール」を押す。5〜15 分かかります。終わったら Claude Code に「入りました」と書く
Windows で「アクセスを許可しますか」（青い画面）や「ユーザー アカウント制御」
「許可」「はい」を押す。道具を入れるときに出ます
AI が同じことを 2 回聞いてくる・前の話を忘れている
会話が長くなったサインです。11 章へ

4人の手が要る 8 つの場面（出てくる順）

指示文には「ここは私の手が要ります。正常です」と AI が先に言う約束を入れてあります。それでも不安なときのために、画面の見え方を書いておきます。

場面何が出るかすること
GitHub（保管庫）登録画面 → メールの確認コード → 2 段階認証の案内。Claude Code からは「8 桁のコードを入れてください」と、入れる先のページ登録して、8 桁のコードをそのページに打つ。2 段階認証は「あとで」でも進めます
Vercel（公開の置き場所）「Continue with GitHub」→ GitHub の許可画面（Vercel にどの保管庫を見せるか）GitHub で入り、許可する。Hobby（無料）は個人利用向けです
Supabase（データ）登録 → 「New project」→ 名前・データベースのパスワード・地域パスワードは自分で決めて紙に書く。地域は Tokyo（Northeast Asia）
OpenAI（会話の AI）登録 → 電話番号の確認 → 支払い（前払い）→ 「API keys」で鍵を作る。鍵は 1 回しか表示されません数ドル〜 10 ドルを前払い。鍵が出たら、その場で 5 章の方法で渡す
Azure（発音の点数）Microsoft アカウント → 電話とカードの確認 → 「Speech」のリソースを作る（価格は F0＝無料枠）→ 鍵と地域F0 を選ぶ。鍵と地域の名前を 5 章の方法で渡す。F0 のまま使えば 0 円です
YouTube Data API（動画を探す鍵）Google Cloud の画面で鍵を作る。無料枠の範囲で足りますAI が道順を出します。鍵は 5 章の方法で
スマホのホーム画面に追加iPhone：Safari の「共有」ボタン（□に↑）→「ホーム画面に追加」。Android：Chrome の「︙」→「ホーム画面に追加」以後はアプリのように開けます。iPhone は必ず Safari から
マイクの許可初めて話す練習を開くと「マイクへのアクセスを許可しますか」「許可」。断ってしまったら、スマホの設定 → Safari（または Chrome）→ マイク から直せます

5鍵の貼り方（会話欄に貼らない）

鍵（API キー）は、合言葉のようなものです。会話欄に貼ると記録に残ってしまいます。

  1. Claude Code に「鍵を入れる窓を開いて」と言う。AI が設定ファイル（.env.local）をメモ帳のような窓で開きます
  2. 鍵をその窓の指定の行に貼って保存する
  3. Claude Code に「貼りました」と書く。AI が中身を見ずに「読めた」とだけ確かめます
もし会話欄に貼ってしまったら：「その鍵は無効にして、作り直して」と言い、サービス側で古い鍵を削除する

6赤い字（エラー）が出たら、3 手順

  1. 赤い字を全部選んでコピーする（長くて構いません）
  2. Claude Code に貼って、「直して」と書く
  3. 直ったと言われたら 「確かめて」と書く。AI が実際に動かして確認します
同じエラーが 3 回続いたら：「別の方法で」と言う。1 つの道に固執しているときに効きます
何が起きているか分からなくなったら：「いまどこ？」と言う。「ここまで済んだ／次にあなたがすること 1 つ」が返ってきます

7Windows の早見表

症状意味言う言葉
cannot be loaded because running scripts is disabledPowerShell が、道具の実行を止めているそのまま貼って「直して」。AI が自分の範囲だけ許可に変えます
'claude' は、内部コマンド…として認識されていません黒い画面から呼ぼうとしているデスクトップアプリの「Code」タブを使う（2 章）
Defender の警告・「WindowsによってPCが保護されました」入れた道具を Windows が警戒している「詳細情報」→「実行」。出どころが AI の案内したものなら進めてよい
日本語が「???」や「縺」になる文字コードの違い「文字化けしている。UTF-8 で直して」
作ったフォルダが OneDrive の中にある同期で重くなる「OneDrive の外に移して」。自分の名前のフォルダ直下へ
自分の名前のフォルダが日本語一部の道具が日本語のパスで止まることがある止まったら「日本語のフォルダ名が原因か確かめて」。別の場所（C:\EnglishLab など）に移す案を AI が出します

8Mac の早見表

症状意味言う言葉
「コマンドラインツールをインストールしますか」最初に 1 回要る部品「インストール」を押して待つ（3 章）
Password: で止まるMac のパスワードを求めている打って return（文字は出ません）
command not found: claude黒い画面から呼ぼうとしているデスクトップアプリの「Code」タブを使う（2 章）

「開発元を確認できないため開けません」Mac が警戒しているシステム設定 → プライバシーとセキュリティ → 「このまま開く」。AI の案内したものだけ

9アプリの早見表

症状意味言う言葉
公開した URL を開くと「Application error」公開側で落ちている。パソコンでは動いた、がよくある「本番のログを見て、原因を直して」
動画の字幕が「ありません」と全部に出る公開側（クラウド）からは字幕が取れないことが多い。本当に無いとは限らない「字幕は私のパソコンで取る方式にして」。指示文にも書いてあります
字幕が急に全部失敗するようになった短時間に取りすぎて、YouTube に止められた（丸 1 日ほど続く）／字幕の取り方が YouTube 側の変更で壊れた「1 日待ってから、もう一度」。それでも駄目なら「別の取り方に切り替えて」
アプリが開かない・「Project paused」無料のデータベースが、しばらく触らないと眠るSupabase の画面で「Restore」を押す。あとで「毎日 1 回読みに行く見張りを入れて」
声が録れない・聞き取らないマイク許可／iPhone はホーム画面のアプリから開くと動かないことがあるマイク許可を確認（4 章）。iPhone は Safari で開いて試す
長い会話のあと、記録が丸ごと消えた講評の文章が長すぎて途中で切れた「講評が途中で切れて保存されない。出力を短くして、切れても保存されるようにして」
「動きました」と言われたのに、スマホで見ると変わっていない公開に数分かかる／別の版を見ている3 分待って再読み込み。駄目なら「本番に反映されたか確かめて」

10お金の見張り方

  • OpenAI：前払い式なので、入れた金額以上は使われません。「Billing」の画面で月の上限（Budget）も決められます。場所が分からなければ AI に「OpenAI の月の上限を決める画面への道順を出して」
  • Azure：Speech を F0（無料枠）で作っていれば 0 円。F0 のままかは「価格レベル」で分かります
  • Claude：月額固定。時間あたりの枠はありますが、追加料金はありません
  • Vercel・Supabase・GitHub：無料枠。個人で使う範囲で超えることはまずありません
  • 月に一度、AI に 「今月いくら使った？」 と聞く。概算を出してくれます

11会話が長くなったら

長い会話は、AI が前の話を忘れたり、動きが遅くなったりします。目安は「同じ説明を 2 回させたとき」です。

  1. いまの会話で「進み具合.md を最新にして」と言う（指示文で、段が終わるたびに書く約束になっています）
  2. 新しい会話を開く
  3. 「進み具合.md を読んで、続きをやって」と書く。AI が現在地を読み直して続けます

12人に聞く前に

人に聞くときは、次の 2 つを添えると、ひとことで答えが返ってきます。

  • Claude Code に「いまどこ？」と聞いた答え（コピー）
  • 出ている赤い字（コピー）

この手引きに無い止まり方をされたら、それを教えてください。書き足します。

案内の本編は English Lab の作り方。この手引きは、Claude Code の公式ドキュメント（概要・導入）と、私自身が半年で踏んだ止まり方をもとに書いています。各サービスの画面は変わることがあるので、見え方が違っていたら AI に「いまの画面はこうなっている」と伝えてください。患者さん・お客様の情報は、どこにも入れない前提です。
